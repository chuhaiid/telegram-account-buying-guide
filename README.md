## 三种弹窗:都不是账号坏了

**Please check your internet connection and try again**,带 OK 和 Use Proxy 两个按钮。这是网络没生效,和账号无关。回到验网络那一步。

**Add Email**,要求绑定邮箱。这是最常见的情况,很多账号没绑过邮箱,Telegram App 会在登录时要求先绑一个。两种处理:绑自己的常用邮箱,邮箱收验证码填回去,以后这个邮箱还能帮你找回账号;不想绑就用浏览器打开 web.telegram.org,点 LOG IN BY PHONE NUMBER,后面步骤完全一样。也可以用接码页底部提供的第三方客户端。

**SMS Fee**,紫色金币页面要求付费开会员。这是 Telegram 的风控,多半是线路太多人共用。不要付费,改用网页版或第三方客户端登录。

商品页把这三种情况都归为「不属于账号问题,不可售后」,因为换一种登录方式就能过去。

## 登录成功之后:当天必做三件事

这是我觉得整篇文章最重要的一段。很多人登上就不管了,过两周换手机,发现再也登不回去。

**第一件,再登一台设备。** Telegram 以后的登录验证码会发到你已经登录的设备上。成品号没有 SIM 卡在你手里,设备全部退出,就再也取不到验证码——这是 Telegram 的机制,不在任何商家的质保范围内。做法:用电脑或另一部手机打开 web.telegram.org 显示二维码,在已登录的手机上进 Settings → Devices → Link Desktop Device 扫码。两台都保持登录,不要退出。

**第二件,改两步验证密码。** Settings → Privacy and Security → Two-Step Verification → Change Password,先输接码页给的旧密码,再设新的,记在安全的地方。改完之后,别人即使拿到验证码也进不来。

**第三件,先静置几天。** 刚登录不要马上大量加群、群发私信、改头像昵称,也不要频繁切换线路,固定一条用。

还有一个坑:Devices 里会看到一个叫 Telegram API 的会话,那是接码链接用的设备。想清掉它,等登录满 24 小时后单独点它结束;清掉以后接码链接就取不到码了,这无所谓,反正它只能用一次。但**千万不要点 Terminate All Other Sessions**,那会把你自己的第二台设备也踢掉。

关于绑邮箱:Telegram 的登录邮箱是官方内测功能,不是所有账号都开放,商品页标注为不保证可绑定。账号开放了就绑上,多一条找回路径;没开放就只能靠设备在线加两步验证密码。

## 风控与售后:边界在哪

**风控。** Telegram 对垃圾信息的处理写在官方的垃圾信息常见问题里:用户举报,审核团队认定,账号被临时限制,只能给存了你号码的人发消息、只能回复先找你的人。第一次且不是大规模发送的,限制通常几天后自动解除;重复违规时间更长。确信误判,渠道只有一个:在 Telegram 里联系官方的 @SpamBot。冻结则更重:账号变成只读,应用内可以提交申诉。这些都发生在登录之后,商品页写明不在质保范围,「开通会员可以缓解,但不能完全避免」。

**售后。** 范围:交付的手机号或接码链接无法完成首次登录。时限:下单后 24 小时内。方式:带订单号和完整的报错截图,点页面右下角在线客服,并停止重复尝试登录。终点:首次登录成功即交付完成,质保结束。号码提示 This phone number is banned 的,截图、保存订单号、联系客服。

**Too many attempts。** 每获取一次验证码,风控计数加一次,越试越难登。出现这个提示就停下来,等几个小时,换个网络再试。首次登录失败之后反复点发送,是最常见的把一个好号试坏的方式。

买的时候很多人会问美国号是不是更好。商品页对各国号码的说明是一致的,没有标注功能差异,质保口径也一样;Telegram 官方也不按号码国家区分账号功能,群组、频道、消息对所有号码一样。号段真正的区别只有两处:一是别人看你资料时的观感,美国、加拿大、英国这类区号更常见;二是 Telegram 对某些国家号码的注册验证方式不同,比如前面说的付费验证,但成品号已经注册完成,首次登录走接码链接,这一步你碰不到。所以在意观感就选常见区号,只是自用就按在售档位挑,需要特定国家就先看它在哪一档有货——比如中国台湾只在 180 天档,马来西亚只在 1 年档。

## 常见问题

**Q:收到的为什么是手机号和链接,不是账号密码?**

A:不能。它只供首次登录使用。登录后让两台设备在线,以后的验证码会发到已登录设备上。
